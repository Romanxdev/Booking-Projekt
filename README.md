Projektet blev skabt med udgangspunkt i et konkret problem: Zealands lokaler stod ofte tomme uden for undervisningstid, samtidig med at studerende manglede stille studiepladser.

Løsningen blev et digitalt bookingsystem, hvor studerende nemt kan reservere ledige lokaler via en brugervenlig platform. 

Perspektiv for videreudvikling:
En fremtidig udvidelse kunne give eksterne virksomheder mulighed for at leje lokaler mod betaling. Det kan potentielt skabe nye indtægtskilder for Zealand og reducere afhængigheden af statslige tilskud-
